Cadastros do Atende

O campo original OBJETO nunca é alterado. Para OBJETO vazio/null, a classificação visual aceita somente PRODUTO ECT ou SEM REGISTRO. Faça várias classificações e use Salvar alterações para gravar o lote exibido.
O código original do Atende permanece no RAW. O nome cadastrado aqui passa a ser exibido na coluna e no filtro ATENDENTE.
Importação por CSV: use exatamente Contrato; Ocorr.; Cliente; Tipo; Intermediador. Ocorr. é calculada pelo RAW e existe no CSV apenas para manter a mesma estrutura visual.
Cada nome recebido do Atende vira um alias permanente do cliente mestre. Para carga inicial por CSV, use Nome recebido do Atende; Nome correto; Cliente existente (opcional); Local padrão. Deixe Cliente existente vazio ou escreva Criar novo cliente para criar/reutilizar o cliente pelo Nome correto. O CSV operacional dos Correios continua intacto.
