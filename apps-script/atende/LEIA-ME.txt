PAINEL ATENDE - AGF JOSE BONIFACIO
VERSAO v19 - IMPORTACAO AUTOMATICA DO CSV DIARIO

OBJETIVO
Preservar todo o fluxo v18 de JSON e acrescentar uma nova fonte automatica:
o relatorio CSV diario salvo na pasta _Atende Diario do Google Drive.

FLUXO NOVO
Drive
-> gatilho horario Apps Script
-> validacao do CSV
-> upsert por Objeto ou ATENDIMENTO
-> aba Postagens
-> indice/cache
-> painel /atende

ARQUIVOS NOVOS
- 20_ATENDE_CSV_CONFIG.gs
- 21_ATENDE_CSV_IMPORT.gs
- 22_ATENDE_CSV_PARSER.gs
- 23_ATENDE_CSV_IDEMPOTENCIA.gs

- 25_ATENDE_CSV_HELPERS.gs

ARQUIVOS PRESERVADOS
- Code.gs
- Index.html
- zz_PerformancePatch.gs
- appsscript.json

O QUE CONTINUA FUNCIONANDO
- JSON de postagem
- JSON de atendimento/enriquecimento
- busca e filtros
- paginacao
- resize de colunas
- indice de datas
- cache do painel
- regra de nao duplicar objetos

REGRA DO CSV
- Registro com CODIGO_OBJETO usa o objeto como chave.
- Registro sem CODIGO_OBJETO tambem e importado.
- Nesses casos, Objeto permanece vazio no painel.
- O campo ATENDIMENTO real do CSV e guardado como nota tecnica na celula Objeto.
- Nenhum codigo de objeto artificial e criado.
- Se um objeto ja existir, o CSV pode enriquecer/atualizar campos conhecidos.
- Status de rastreio avancado nao e rebaixado para Postado.
- Estorno pode atualizar o status para Estornado.

PERFORMANCE
- O CSV nunca e processado durante o carregamento do painel.
- Novas linhas sao escritas em lote.
- Atualizacoes sao feitas em blocos.
- LockService evita execucoes concorrentes.
- Cache e indice de datas sao atualizados uma vez ao final do lote.

CONFIGURACAO OBRIGATORIA
No Apps Script:
Project Settings
-> Script Properties
-> ATENDE_CSV_FOLDER_ID = ID da pasta _Atende Diario

PRIMEIRO TESTE
1. Faca o clasp push da versao v19.
2. Configure ATENDE_CSV_FOLDER_ID.
3. Execute ATENDE_validarCsvDriveSemGravar().
4. Para o arquivo baseline de 05/09/2026, o esperado e:
   - totalRows = 980
   - importableRows = 980
   - validObjects = 965
   - withoutObject = 15
   - invalidMissingKey = 0
5. Confirme que a validacao nao adicionou linhas.
6. Execute ATENDE_importarCsvDriveAgora().
7. Confira Postagens e LOG_IMPORTACOES.
8. Abra /atende e valide os dados do novo dia.
9. Somente depois execute ATENDE_instalarGatilhoCsvDrive().

GATILHO
ATENDE_instalarGatilhoCsvDrive() instala um unico gatilho a cada 1 hora.
Executar a funcao novamente remove gatilhos duplicados desse handler antes de criar o novo.

STATUS
ATENDE_statusCsvDrive() informa se a pasta esta configurada e os gatilhos existentes.

REMOVER GATILHO
ATENDE_removerGatilhoCsvDrive()

REVERSAO
1. Remova o gatilho.
2. Volte para a versao anterior no Git.
3. Faca clasp push.
4. Se precisar remover o primeiro lote importado, crie backup e use LOG_IMPORTACOES para identificar o lote antes de apagar qualquer linha.
