PAINEL ATENDE - AGF JOSÉ BONIFÁCIO
VERSÃO v19 - REDESIGN DO PAINEL OPERACIONAL

ARQUIVOS DO PACOTE
- Code.gs                 Backend Apps Script completo
- Index.html              Frontend completo
- appsscript.json          Manifesto Apps Script
- .clasp.json              Configuração clasp preservada
- LEIA-ME.txt              Este roteiro

OBJETIVO DA VERSÃO
Melhorar a leitura gerencial e operacional do painel sem alterar o backend, a estrutura canônica dos dados ou as rotinas de importação.

MELHORIAS VISUAIS
- Remove o segundo cabeçalho duplicado de dentro do Apps Script, já que /atende/ possui shell permanente no portal.
- Cria resumo operacional compacto acima da tabela.
- Adiciona KPIs calculados no navegador a partir do recorte filtrado:
  - registros;
  - valor das postagens;
  - ticket médio;
  - entregues;
  - itens que exigem atenção.
- Adiciona distribuição de status em chips semânticos.
- Os KPIs respondem imediatamente aos mesmos filtros da tabela.
- Reorganiza espaçamentos, contraste, cartões, sidebar e tipografia.
- Mantém layout responsivo para desktop, tablet e celular.
- Preserva filtros rápidos, filtros por coluna, ordenação, paginação e resize das colunas.

FUNCIONALIDADE PRESERVADA
- Parser robusto de JSON de postagem e atendimento.
- Tipo Postagem       <- JSON de postagem
- tipo                <- exclusivamente at.tipo do JSON de atendimento
- formaPagamento      <- at.pagamentos[0].formaPagamento
- codigo              <- at.itens[].codigo
- descricao           <- at.itens[].descricao
- vínculo             <- at.itens[].codigoObjeto = coluna Objeto
- Busca, filtros, paginação, ordenação e redimensionamento das colunas.

COMO INSTALAR
1. No projeto Apps Script do Atende, substitua integralmente Index.html pela versão deste repositório.
2. Code.gs não precisa ser alterado para este redesign.
3. Salve o projeto.
4. Faça uma nova implantação do Web App.
5. Abra https://minhaagenciaonline.com.br/atende/ em aba anônima para validar a nova implantação.

CHECKLIST DE TESTE
1. Abra o painel e valide o carregamento da tabela.
2. Confirme que existe somente o cabeçalho permanente do portal e que o iframe começa pelo resumo operacional.
3. Confira os KPIs sem filtros e depois aplique busca, data, atendente e demais filtros rápidos.
4. Confirme que registros, valor, ticket, entregues, atenção e status mudam junto com o recorte.
5. Cole o JSON de postagem e valide Processar.
6. Cole o JSON de atendimento e valide Enriquecer.
7. Teste filtros de coluna, ordenação, paginação e resize.
8. Teste o botão Planilha quando o link estiver disponível.
9. Valide desktop e celular.

REVERSÃO
Se houver qualquer comportamento inesperado, volte à implantação anterior do Web App. Esta versão altera apenas o frontend e não remove dados nem modifica a estrutura canônica.
