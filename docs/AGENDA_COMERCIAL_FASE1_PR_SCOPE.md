# Agenda Comercial — Fase 1 — Escopo do PR

O PR desta branch deve revisar somente:

- suporte canônico a AVULSA;
- schema aditivo;
- duração por tipo;
- workspace AVULSA enxuto;
- dias úteis;
- filtros de vencidas;
- documentação correspondente.

Não inclui redesign amplo nem definição definitiva da visão Diária como padrão.
